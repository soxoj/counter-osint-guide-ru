# Сборка книги

Из текста руководства собираются PDF, FB2 и EPUB, которые лежат на
[counter-osint.soxoj.com](https://counter-osint.soxoj.com).

    tools/build.sh ru                                  # русская книга
    tools/build.sh en ../counter-osint-guide-en        # английская

Порядок глав берётся из оглавления `README.md`, поэтому новая страница попадает в книгу
только после того, как появится там. Готовые файлы складываются в `../build/<язык>/`.

Что нужно на машине: `python3`, `wkhtmltopdf` и `pandoc`. Если pandoc не установлен,
скрипт возьмёт его через `uv` (`uvx --from pypandoc-binary`), ставить отдельно не требуется.

Собирать лучше из чистой копии `main` — скрипт печатает ветку и число несохранённых
изменений, чтобы книга случайно не уехала из рабочего черновика.
